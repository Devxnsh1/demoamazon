Amazon Clone

[Amazon Clone Preview](images/screenshot.png)

A modern Amazon homepage clone built using **HTML, CSS, and JavaScript**. This project focuses on creating a clean, responsive user interface inspired by Amazon while practicing front-end development concepts.

## Live Demo
https://devxnsh1.github.io/demoamazon/

## GitHub Repository
https://github.com/Devxnsh1/demoamazon

##  Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)

##  Features
- Amazon-inspired homepage UI
- Sticky Navigation Bar
- Sticky Menu Panel
- Hero Banner Section
- Product Cards with Hover Effects
- Interactive Search Bar
- Smooth Scrolling
- Back to Top Button
- Clean & Responsive Layout
